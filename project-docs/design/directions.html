A · The Ledger

An auditor's ledger: paper, ruled lines, a serif for figures, and a red-ink "DENIED" stamp that only lands once the gate allows it. The idea is that every decision here is a permanent record. It reads as serious, regulatory and distinctive. It is the furthest from a generic SaaS look.

B · The Checkpoint

A security checkpoint: dark, live telemetry, a LOCKED line between the agent and the claims system, the eight gate checks lighting up as you meet them, and a transaction log streaming on the right. It sells "the agent cannot get through" most dramatically on a projector.

C · The Case File

A clinical case file: calm teal, soft panels, a folder tab, and each piece of evidence as a document card with a progress ring. It is the friendliest for the reviewer and the most like a real healthcare product.
